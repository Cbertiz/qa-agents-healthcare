# US-01: Agendar consulta

Como afiliado activo, quiero agendar una consulta con un especialista
para no tener que llamar por teléfono.

## Criterios de aceptación
- El afiliado puede elegir especialidad, médico y horario disponible.
- No se puede agendar si el afiliado tiene deuda.
- Se envía una confirmación después de agendar.
- Un afiliado no puede tener más de 2 consultas pendientes con la misma especialidad.
